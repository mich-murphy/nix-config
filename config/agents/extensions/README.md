# Pi extensions

This directory contains the source for global Pi coding-agent extensions
maintained in this repository. Home Manager packages extensions with npm
dependencies and links each repository-owned entry into the otherwise mutable
`~/.pi/agent/extensions` directory. Pi discovers top-level TypeScript files and
subdirectories containing an `index.ts` entry point.

Keep source, tests, package manifests, and lockfiles here. Do not commit
`node_modules`, credentials, upstream package contents, or integration files
generated by external tools. Install third-party Pi packages with Pi's package
manager and let vendor integration installers own their generated files. Each
locally packaged extension pins its npm dependency closure with `npmDepsHash`
in `home/coding-agents.nix`. Update that hash when its lockfile changes.

Home Manager deliberately does not own the containing extension directory.
Herdr, Moshi, and other external installers can therefore add or update their
generated integration entries without writing into the Nix store. Name
repository-owned entries explicitly in `home/coding-agents.nix` so Home Manager
and external installers never claim the same path.

Rebuild and activate Home Manager after changing extension source or lockfiles,
then restart Pi or use its `/reload` command.
