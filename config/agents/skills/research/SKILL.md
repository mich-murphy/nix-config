---
name: research
description: Investigate a question against high-trust primary sources and report the findings directly. Use when the user wants a topic researched, docs or API facts gathered, or reading legwork delegated to a background agent.
---

Spin up a **background agent** to do the research, so you keep working while it reads.

Its job:

1. Investigate the question against **primary sources** (official docs, source code, specs, first-party APIs), not a secondary write-up of them. Follow every claim back to the source that owns it.
2. Report findings directly. Create a Markdown artifact only when the user
   explicitly requests one.
