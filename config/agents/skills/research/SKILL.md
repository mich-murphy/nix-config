# Research

Use web tools to research a given question via the following steps:

1. Separate the research question from implementation and local inspection.
2. Define a concrete completion condition, a budget of at most five primary
   source pages, and an output limit of at most 800 words.

Require first-party documentation, specifications, source code, or official APIs
and exact source URLs.

Report findings directly. Create a Markdown artifact only when the user
explicitly requests one.
